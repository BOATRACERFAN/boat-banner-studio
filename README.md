# BOAT BANNER STUDIO

ボートレース選手を応援する、960×192pxのデジタル横断幕エディター。React / TypeScript / Vite / react-konva / Zustand / Tailwind CSSを使用した静的Webアプリです。サーバー、データベース、ログイン、APIキー、有料APIは不要です。

## 起動とビルド

Node.js 22.12以上とnpmを使用してください。

```sh
npm ci
npm run dev
```

ターミナルに表示されるURLを開きます。別アプリとポートが重なる場合は `npm run dev -- --port 5184 --strictPort` を使用してください。

```sh
npm run build
npm run preview
```

`dist/` にHTML / CSS / JavaScriptが出力されます。`index.html`をファイルとして直接開かず、HTTPサーバーで配信してください。

## 操作

1. 左側のテンプレート・背景・装飾・文字・配色から素材を選びます。検索、カテゴリ、お気に入りに対応しています。
2. 右側の「選手情報」で選手名、ふりがな、登録番号、支部、応援メッセージを変更します。対応するテキストレイヤーへ同期します。
3. キャンバスの要素をクリックして選択し、ドラッグで移動します。ハンドルで拡大縮小・回転できます。文字はダブルクリックで直接入力します。
4. Shift＋クリック、またはレイヤーのチェックボックスで複数選択します。グループ化、まとめて移動・変形、整列、反転、重ね順、複製、表示、ロックに対応しています。
5. 「おまかせデザイン」は指定したテイストの構図を使い、背景と装飾を組み合わせます。生成後のすべてのレイヤーを編集できます。
6. 「保存」でこのブラウザーへ保存します。「別のプロジェクトとして保存」で複数管理できます。「プロジェクト」からJSONを書き出し・読み込みできます。
7. 「ダウンロード」で選手情報と応募前の事項を確認し、PNG / JPEGを保存します。

スマートフォンでは専用の編集画面になります。上にプレビューを残し、下部の「デザイン・文字・背景・飾り・その他」で操作を選びます。

- 「文字」の大きな一覧から選手名などをタップすると、内容・書体・大きさ・色を編集できます。プレビュー上の文字や飾りをタップして選ぶこともできます。
- 最初は拡大表示です。「全体」で完成形を確認し、「拡大」で細かく編集できます。「表示位置」のスライダーで左右を見渡せます。
- 「文字・飾りを動かす」をタップすると「画面を動かす」に切り替わり、指で横にスクロールできます。もう一度タップすると要素の移動へ戻ります。
- 「位置・傾きを調整」には5pxずつ動かす矢印、中央配置、回転があります。「詳細」からフチ・影・重ね順など従来の設定も使えます。
- 配色、ランダム生成、保存デザイン、レイヤー一覧、使い方は「その他」にあります。画像保存は右上の「ダウンロード」です。
- 横向きではプレビューと設定を左右に並べます。タブレット幅では従来の素材・設定パネルを使用します。

## 収録数

| カタログ       | 件数 | 内容                                                 |
| -------------- | ---: | ---------------------------------------------------- |
| 背景           |   60 | 12カテゴリ×5。構図・図形・パターンの異なる独自SVG    |
| 装飾           |  100 | 10カテゴリ×10。色・変形を変更できる独自SVG           |
| 日本語フォント |   30 | Google Fontsから遅延読み込み                         |
| 英字フォント   |    2 | Bebas Neue、Orbitron。日本語部分にNoto Sans JPを併用 |
| 配色           |   42 | 背景・テキスト・装飾を一括変更                       |
| 文字エフェクト |   17 | フチ、二重フチ、影、グロー、グラデーション、立体など |
| テンプレート   |   30 | 5通りの文字組みと異なる素材・配色・書体の組み合わせ  |

背景は色違いの複製ではなく描画構成を変えています。装飾は同一色でも異なる図形です。テンプレートは合成済み画像ではなく、5つの文字レイヤーと2〜4つの装飾レイヤーへ展開されます。

## 画像・フォント・保存

- 表示倍率20〜200%と出力解像度は独立しています。PNG / JPEGは必ず960×192pxです。
- PNGの透明出力では背景プリセットとアップロード背景を省き、文字・装飾・画像レイヤーを残します。
- JPEGは指定した合成背景色で透明部分を塗り、品質80〜100%で保存します。
- 出力名は `選手名_登録番号_960x192.png` / `.jpg` です。
- プレビューと出力は同じKonvaシーンを使用します。出力専用の複製から選択枠・ガイドを除去します。
- 日本語フォントはCSSと必要な文字の読込を待ち、読込後に文字レイアウトを再計算します。失敗時は出力を停止し、再試行できます。
- Google Fontsの初回読み込みにはインターネット接続が必要です。TTF / OTF / WOFF / WOFF2の独自書体も追加できます。独自書体の日本語対応・利用許諾は利用者が確認してください。
- PNG / JPEG / WebPを8MBまでアップロードできます。長辺を1920px以下に縮小して保存容量を抑えます。背景の位置・倍率を設定し、キャンバス外をトリミングします。
- 550msの待ち時間後にlocalStorageへ自動保存します。履歴は60操作、保存プロジェクト30件、レイヤー250個、独自フォント10個までです。
- 画像やフォントのデータをJSONへ含めるため、JSONから別端末でも復元できます。スキーマは `schemaVersion: 1`。未知のバージョン、不正な図形・色・数値、外部画像URLなどを検証して拒否します。
- ブラウザーの容量が不足した場合は通知し、JSONでの保管を促します。ブラウザーのデータ削除やプライベートモードで保存データが失われることがあります。
- ガイドは枠外の要素、テキスト枠への収まり、単純な文字色・背景色のコントラストをチェックします。複雑な背景画像の視認性は目視でも確認してください。

## GitHubへ公開

このフォルダーをリポジトリのルートとして使用します。`node_modules`、テストの一時ファイルは含めません。

```sh
git init
git add .
git commit -m "Build BOAT BANNER STUDIO"
git branch -M main
git remote add origin https://github.com/YOUR_ACCOUNT/boat-banner-studio.git
git push -u origin main
```

GitHub上で空のリポジトリを先に作成し、URLを自分のものへ置き換えてください。既存リポジトリの場合は通常のブランチ・コミット手順に従ってください。

## Cloudflare Pagesへ公開

1. Cloudflareの **Workers & Pages** からPagesプロジェクトを作成し、GitHubリポジトリを接続します。
2. 次のビルド設定を指定します。

| 設定                   | 値                     |
| ---------------------- | ---------------------- |
| Framework preset       | React / Vite           |
| Production branch      | main                   |
| Build command          | npm run build          |
| Build output directory | dist                   |
| Root directory         | リポジトリ直下なら空欄 |

3. デプロイが成功したら `*.pages.dev` のURLを開き、フォント・編集・画像保存を確認します。

環境変数・シークレットは不要です。`.node-version` はNode 22を指定しています。Cloudflare Pagesの静的配信では `dist/` 全体を使用します。

公式資料：[ReactをPagesへデプロイ](https://developers.cloudflare.com/pages/framework-guides/deploy-a-react-site/) ・ [ビルド設定](https://developers.cloudflare.com/pages/configuration/build-configuration/)

### 独自ドメイン

Pagesプロジェクトの **Custom domains** → **Set up a custom domain** からドメインを追加します。画面の指示に従ってDNSレコードを設定してください。ルートドメインを使用する場合はCloudflareへゾーンを追加し、ネームサーバーを指定する必要があります。サブドメインは案内されたCNAMEを設定します。DNSと証明書の状態がActiveになったらHTTPSで動作確認してください。

公式資料：[Custom domains](https://developers.cloudflare.com/pages/configuration/custom-domains/)

この納品にはCloudflareアカウントやGitHubリポジトリの作成・本番デプロイは含まれていません。

## 検証

```sh
npm test
npx playwright install chromium webkit
npm run test:e2e
npm run verify:fonts
npm run build
```

Playwrightは専用の5191番ポートで開発サーバーを起動します。テスト中はコードを編集せず、プレビューとは別のサーバーを使用します。検証にはGoogle Fontsへ接続できる環境が必要です。実ブラウザーの画面と画像は `verification/` へ、テストレポートは `playwright-report/` へ出力されます。

`FONT_VERIFICATION.json` は公式CSSの日本語収録範囲と公式OFLの確認結果です。検証スクリプトを再実行すると最新の結果に更新します。各書体の実画像での確認結果は `verification/browser-fonts.json` を参照してください。

## 拡張と構造

```text
src/
  catalog/       背景・装飾・書体・配色・効果・テンプレート
  editor/        SVG描画、共通Konvaシーン、ZustandとUndo/Redo
  components/    ライブラリ、プロパティ、ダイアログ
  lib/export/    固定解像度での画像出力
  lib/           フォント、画像、JSON検証、保存、ガイド
  types/         プロジェクトとレイヤーの型
tests/           ブラウザー受け入れテスト
scripts/         フォントの提供・ライセンス検証
```

カタログにメタデータを追加し、`editor/artwork.ts` のレンダラーへ対応する図形を追加すれば素材を増やせます。テンプレートは背景・配色・書体・効果・構図・装飾のIDを組み合わせます。既存IDは保存データで使用するため変更しないでください。保存形式を変更する場合はスキーマバージョンと移行処理を追加してください。
